What this system does

A hospital has patients and open clinical trials. This API takes both as input and automatically matches patients to trials they're eligible for — with a full explanation of every decision.

Key features

• Rule-based eligibility (data, not code)
• Partial batch processing (quarantine)
• Three-stage matching pipeline
• Deterministic UUID5 patient IDs
• Exclusion reasons for every decision
• PII masking by default
• Temporal exclusivity checks
• Append-only audit trail
